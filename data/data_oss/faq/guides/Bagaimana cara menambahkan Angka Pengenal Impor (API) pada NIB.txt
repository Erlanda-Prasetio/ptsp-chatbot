QUESTION:
Bagaimana cara menambahkan Angka Pengenal Impor (API) pada NIB?

ANSWER:
Untuk melakukan penambahan atau perubahan Angka Pengenal Importir (API) dapat dilakukan dengan cara berikut: 1. Pilih menu Perizinan Berusaha, Pilih Kelola Usaha kemudian pilih Perubahan dan pilih Perubahan Data Usaha 2. Pada bagian Aktivitas Impor, klik kolom Jenis Angka Pengenal Importir (API). Pilih sesuai jenis API yang diinginkan 3. Centang disclaimer kemudian klik tombol Selanjutnya Sebagai informasi: Perubahan jenis API hanya dapat dilakukan pada akun Badan Usaha. Akun perorangan hanya dapat mengajukan jenis API-P sehingga tidak dapat mengubah jenis API. Perubahan jenis API hanya dapat dilakukan dari API-U ke API-P.
