1. 1. Kunjungihttps://oss.go.id/,pilih“MASUK”.
2. 2. Masukkan Username dan Password Anda sebagai pengelola, lalu klik tombolMASUK.
3. 3. Setelah Anda memasuki Dashboard OSS, klik menuPROFIL
4. 4. Sistem akan menampilkan Data Profil pengelola. Untuk merubah data penanggung jawab, silakan klik tab ‘PENANGGUNG JAWAB’
5. 5. Data Penanggung Jawab akan ditampilkan secara otomati oleh sistem. Silakan klikEDIT FORMuntuk merubah data Penanggung Jawab.
6. 6. Lengkapi Data Penanggung Jawab terbaru, lalu klikSIMPANuntuk menyimpan Data Penanggung Jawab.
