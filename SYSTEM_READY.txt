🔍 SEARCH METHODS EXPLAINED
═══════════════════════════════════════════════════════════════════════════════

vector_only
  • Direct similarity search
  • Fastest, baseline method
  • Best for exact matches

enhanced_vector
  • Vector search + keyword matching
  • Better accuracy for paraphrasing
  • Moderate speed

internet_fallback
  • Fallback to internet search
  • Used when no local results found
  • Expected 0% precision (compares internet to local ground truth)

❓ COMMON QUESTIONS
═══════════════════════════════════════════════════════════════════════════════

Q: Do I need to delete the NEW dataset?
A: No! All datasets coexist in separate Supabase tables.

Q: How do I switch between datasets?
A: Add ?dataset=OLD or ?dataset=COMBINED to API calls.

Q: What happens if I test with the same questions?
A: You get comparable metrics for direct comparison.

Q: Can I add more datasets?
A: Yes! Edit config_datasets.py and add to DATASET_CONFIGS.

Q: Is the old system still available?
A: Yes! Both rag_api.py and rag_api_datasets.py can coexist.

Q: How do I know which dataset is best?
A: Run all three and compare metrics using analyze script.
