REVIEWER A: Methodological Rigor & Formalism

 1. Formal Mathematical Definitions for EVR and VOR

Reviewer Critique: "EVR--VOR Vector Retrieval belum didefinisikan secara formal. Tidak memberikan definisi matematis atau algoritmik yang jelas."

Our Response: We have added explicit mathematical definitions:

-   Vector-Only Retrieval (VOR):
    f_VOR(q) = top-k(cos_sim(E(q), D), k=12)

-   Enhanced Vector Retrieval (EVR):
    f_EVR(q) = top-k(cos_sim(E(q'), D), k=24)

where q' represents domain-specific query expansion. EVR implements a hybrid scoring function:

    S_hybrid(d, q') = α * sim(E(q'), E(d)) + (1-α) * KeyMatch(q', d)

with α = 0.7, and filtering threshold S_hybrid > 0.35.

 2. Multi-Agent Debate Mechanism Formalization

Reviewer Critique: "Mekanisme multi-agent debating masih bersifat deskriptif. Tidak menjelaskan secara rinci peran masing-masing agen, aturan interaksi, atau bagaimana konflik pendapat diselesaikan."

Our Response: We have formalized the debate protocol with explicit algorithm specification:

Algorithm 1: MAF-RAG Debate Protocol

-   Phase 1 (Initial Response): R_i^1 = f_agent(Q, D_i)
-   Phase 2 (Aggregation): A_agg^t = f_agg(R_1^t, ..., R_n^t)
-   Phase 3 (Iterative Refinement): R_i^(t+1) = f_agent(Q, D_i, {R_j^t | j ≠ i})
-   Convergence Criteria: |R^(t+1) - R^t| < ε or t = r_max = 3

The updated Figure 3: Multi-Agent Debate Architecture visually illustrates agent roles (4 independent agents), feedback loops (dashed arrows showing peer refinement), and the aggregator's role in consensus building.

3. Ground Truth Annotation Methodology

Reviewer Critique: "Definisi dan kriteria evaluasi F1-score belum dijelaskan rinci. Tidak menjelaskan bagaimana F1 dihitung dalam konteks RAG."

Our Response: We have provided detailed transparency on F1-score construction:

The ground truth set (G) was established via a Retrieval-Only Verification Run: the system executes with the generative component disabled, isolating optimal retrieval performance. The documents identified in this optimal pass serve as ground truth, eliminating expensive manual annotation while maintaining consistency.

    Precision = |R ∩ G| / |R|
    Recall = |R ∩ G| / |G|
    F1 = 2 * (Precision * Recall) / (Precision + Recall)

Deviations from F1 = 1.0 reflect dataset noise (Legacy) or algorithmic variations (Enhanced/MAF-RAG).

5. Architectural Novelty Positioning vs. MADAM/MAIN-RAG

Reviewer Critique: "Kontribusi konseptual MAF-RAG perlu dipertegas secara structural. Batasan konseptual antara MAF-RAG dan pendekatan RAG yang telah ada belum dijelaskan secara eksplisit."

Our Response: We have expanded the Introduction to explicitly position MAF-RAG:

-   MAIN-RAG: Employs adaptive filtering to remove noise (2-11% accuracy improvement) but lacks deep reasoning for complex multi-document synthesis.
-   MADAM: Addresses hallucination through comprehensive multi-agent debate but applies expensive debate to all queries, resulting in high latency impractical for public services (15.8% improvement on conflicting documents).
-   MAF-RAG (Our Contribution): Introduces a hierarchical escalation protocol that balances speed and rigor by:
    -   Fast path (VOR, 93.3% success): Simple queries resolved in ~0.5s
    -   Medium path (EVR, 89.5% success): Moderate complexity in ~3s
    -   Expensive path (Debate, 50% success): Complex queries only, tertiary fallback after both VOR and EVR fail

Location: Section I (Introduction), Section II (Methodology)

5. Cross-Domain Generalization Discussion

Reviewer Critique: "Generalisasi lintas domain belum dibahas. Artikel belum mendiskusikan apakah arsitektur MAF-RAG dapat secara langsung diterapkan pada domain lain."

Our Response: We have added explicit discussion of architectural modularity:

Section III.D: Cross-Domain Generalization and Modularity

The MAF-RAG architecture is domain-agnostic by design:
- All domain-specific terminology (SIUP, NIB, procedural steps) is externalized to configuration files, not hardcoded
- The three-phase escalation logic (VOR → EVR → Debate) remains domain-invariant
- The multi-agent debate protocol operates on any set of documents without domain-specific modifications

Transition Example: Adapting from government administrative data to hospital procedure documentation requires:
1. Re-vectorizing the new knowledge base with all-MiniLM-L6-v2
2. Updating domain configuration parameters
3. No modification to retrieval logic, debate protocol, or confidence thresholds

This modularity positions MAF-RAG as a general-purpose framework rather than a government-specific solution, supporting rapid deployment across medical, legal, and e-commerce sectors.

6. Future Research Directions

Reviewer Critique: "Arah penelitian lanjutan dapat dipertegas."

Our Response: We have outlined four concrete future research directions in the Conclusion:

1.  Heterogeneous Agents: Replace homogeneous LLM setup with specialized agents (each using different model: GPT-4 for reasoning, Claude for summarization, specialized models for domain analysis)
2.  Adaptive Retrieval: Dynamically switch between "Deep" (expensive, comprehensive) and "Normal" (fast, minimal) retrieval modes based on query complexity prediction
3.  Dynamic Phase Selection: Implement a router model that predicts the necessary escalation phase (VOR, EVR, or Debate) immediately upon query receipt, reducing latency by bypassing unnecessary phases
4.  Continuous Learning (RLHF): Integrate reinforcement learning from human feedback to fine-tune router predictions and agent responses based on real-world user interactions
